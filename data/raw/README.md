# Raw Datasets Directory

This directory holds uncompressed, raw source inspection defect datasets.

## Verified Raw Datasets
- `pipeline_corrosion/` — Mendeley Pipeline Corrosion Image Dataset (Ata et al., 2021)
- `corrosion_condition/` — Mendeley Corrosion Condition Classification & Segmentation (Nash et al., 2022)
- `deepcrack/` — DeepCrack multi-scene surface crack dataset (Liu et al., 2019)
- `mvtec_ad/` — MVTec Anomaly Detection benchmark dataset (Bergmann et al., 2019)

> [!IMPORTANT]
> **Git Exclusion**: Raw image files, archives, and annotations in this directory are strictly excluded from version control via `.gitignore`.
> **Phase 1C Status**: No raw dataset files have been downloaded.
